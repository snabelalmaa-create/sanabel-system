# التاريخ الوردية الكاشير نقدي شبكة آجل الإجمالي مبيعات البرنامج الفرق الحالة

المالية

هذا القسم يحسب الأرصدة كالتالي: النقدي = مبيعات نقدي + قبض العملاء النقدي المعتمد - مشتريات نقدية - مصروفات نقدية - سداد آجل نقدي + الإضافات والتحويلات اليدوية.
البنك = مبيعات شبكة + قبض العملاء تحويل/شبكة المعتمد - مشتريات تحويل - مصروفات تحويل - سداد آجل تحويل + الإضافات والتحويلات اليدوية.
الآجل = مبيعات الآجل - جميع سندات قبض العملاء المعتمدة بأي طريقة سداد + التسويات والتحويلات اليدوية.
يمكنك أيضًا تسجيل إيجار الموقع المؤجر مثل موقع الخضار من خلال سند قبض العملاء، وسيُرحّل تلقائيًا إلى النقدي أو البنك حسب طريقة السداد المختارة بعد الاعتماد.
